الإعدادات ومزامنة Google Drive

المزامنة غير مفعلة بعد. بياناتك الحالية محفوظة في هذا المتصفح.
خطوات الإعداد مرة واحدة
  1. انشر مجلد البرنامج على استضافة HTTPS مثل GitHub Pages أو Netlify؛ فتح الملف محليًا لا يسمح بالمزامنة بين الأجهزة.
  2. افتح Google Cloud Console وأنشئ مشروعًا، ثم فعّل Google Drive API.
  3. أكمل إعداد OAuth consent screen، وأضف بريدك ضمن Test users إذا كان التطبيق في وضع الاختبار.
  4. أنشئ OAuth Client ID من نوع Web application، وأضف عنوان موقعك ضمن Authorized JavaScript origins.
  5. الصق Client ID أدناه في كل جهاز، ثم اضغط «الاتصال بحساب Google» واسمح بالوصول إلى مساحة بيانات التطبيق في Drive.

يستخدم البرنامج نطاق drive.appdata للوصول إلى مجلد بيانات خاص بالتطبيق، ولا يطلب الوصول إلى ملفات Drive الشخصية الأخرى. لا تشارك Client ID مع غيرك باعتباره سرًا، فهو ليس كلمة مرور. المزامنة تعمل عندما يكون التطبيق مفتوحًا ومتصلًا بالإنترنت.
